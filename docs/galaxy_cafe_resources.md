# Galaxy Cafe

The Galaxy Cafe Project is an intermediate level python programming project where the candidate will build a text-based simulation of an intergalactic cafe where patrons from various alien species can order and enjoy unique menu items.


A detailed project specification and rubric is available from the 17D BOLC curriculum:

[The Cosmic Cup / Galaxy Cafe](https://ccds.pages.levelup.cce.af.mil/training/basic/curriculum/07_Python_Programming/Practice_Projects/galactic_cafe/cosmic_cup.html)
